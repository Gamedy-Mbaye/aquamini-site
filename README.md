# Aquamini — aquamini.world

The official site of Aquamini, a DJ duo from Spain. One self-contained file.

## How this site works
- `index.html` is the entire site: design, content, images (embedded), interactions.
- `CNAME` tells GitHub Pages the site lives at aquamini.world. Don't delete it.
- Every push to `main` redeploys the live site automatically within about a minute.

## Making changes with Claude Code
Clone the repo, then just ask, for example:
- "Add a gig at [venue] in [city] on [date] to the Coming up list"
- "Swap --ph-him and --ph-her in the CSS :root with these two photos" (attach photos)
- "Change the mix list to feature [new mix url]"
Then let Claude Code commit and push. The live site updates itself.

## Design system: "The Chop"
Full art direction and decisions live in the Aquamini project (brand/discovery-brief.md).
Short version: images are always built from cut pieces (strips, patches), cream + ink + one red,
strict editorial grid, no decoration, no sound, the funnel is the Listen buttons.
